# v0.4.2 · 五套模板审美重构

2026-10-02。不新增功能，重做五套模板的整体视觉：调色对比统一为对切图，收尾图改为意境化的淡出横幅，字号整体收敛，每套模板有独立的配色、字体层级与细节语言。项目数据结构不变。

## 调色对比

- 每组对比都是一张对切图：左半原始画面、右半调色成片，中间分割线，角上贴 Before／After 小标签。
- “左半原始画面 · 右半调色成片”的提示只在第一张出现一次；每组的说明文字接在图片下方。
- 不再输出“上下排列”和额外的并排列表。只有两张图尺寸不一致（无法如实对切）的一组仍左右并排。
- 界面中去掉“对比图片布局”区块、章节内的“本章节布局”下拉框和预览底部的布局文字。存储中的布局字段保留，旧项目照常打开，统一按对切图输出。

## 收尾图

- 收尾图改为全宽横幅，四周淡出融进页面，略降饱和并加一层柔光，按模板取不同意境：Editorial 暖光、Cinematic 宽银幕光晕、Archive 褪色档案照片、Correspondence 晒褪的信中照片、Gallery 展厅聚光。
- 结束语放在横幅下方，居中、留白：Editorial「这一天，就此珍藏。」、Cinematic「Fin.」、Archive「Archived, with care.」、Correspondence「Yours, always.」（名字与日期做成邮戳）、Gallery「愿这些画面，常看常新。」。
- 横幅下方的小图注不再重复日期。
- 收尾横幅是全文唯一会裁切照片的位置（`object-fit:cover`，取画面中部）。其余画面仍不裁切。

## 模板审美重构

每套模板新增独立样式层（`src/rendering/themes/`），在所有样式之后加载：

- **Editorial**：慢生活画册。象牙纸色、柔和墨色、古铜点缀；居中开篇、细线、衬线细体标题、旧式数字页码；交付卡只留上下细线。
- **Cinematic**：文艺片片头与场刊。暖墨黑底、烟灰文字、黄铜点缀；场景卡式章节（SCENE 01 与时间码）、极简电影票、高光在同一条胶片里、片尾字幕式附录。
- **Archive**：档案目录。石灰麻色纸、墨绿文字、铜绿点缀；88px 索引栏网格，所有文字对齐同一条线；图片装白色衬卡并附 FIG. 编号；交付卡为索引卡。
- **Correspondence**：手写信笺。奶油纸色、玫瑰棕墨、陶土玫瑰点缀；双细线、火漆、圆形邮戳；章节如信件抬头（Note 01.），交付卡为信封式，图片加纸边并轻微倾斜（不超过 1°）。
- **Gallery**：夜间美术馆。蓝灰墨色墙面、暖白文字、浅金点缀；每张图有画框、衬卡与聚光；章节如展厅标题，交付卡如展签。

字号整体收敛：封面姓名 30–38px、章节标题约 21px 常规字重，标签为小号字距排版。分享卡按各模板语言重做（杂志页、电影海报、档案索引卡、明信片、展览邀请函）。模板选择界面的样例卡与模板默认色同步为新配色。

## 修正

- 收尾淡出改为两层单方向遮罩（横向在外框、纵向在内框）。Chromium 打印 PDF 时忽略 `mask-composite`，原写法在 PDF 中左右两侧不会淡出。

## 升级与历史文件

工作区兼容标记仍为 4，可直接打开 v0.4.x 的工作区，无需迁移。渲染器标记升级为 `studio-renderer-8`：旧成功文件保留原样，已生成的候选结果需要重新渲染，旧失败任务需新建导出。
