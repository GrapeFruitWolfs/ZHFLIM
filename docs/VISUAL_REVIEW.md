## 本轮修改

- Editorial、Correspondence 的辅助文字加深，交付正文统一使用正文颜色。
- 五套模板的对比图标签统一为 12px；Gallery 的日期值从 13px 提升为 15px，日期标签从 7px 提升为 10px。
- 格式说明从 9px 提升为 12px；二维码操作标题提升为 14px，域名提升为 12px。
- 字号以 432px 的渲染版面为基准；在 375px 手机宽度显示时会等比缩小。装饰性英文小标题仍是辅助层级。
- 渲染器版本更新为 `studio-renderer-3`。已保存的成功产物仍保留；跨渲染器版本的历史失败任务需从当前项目新建导出。
- 浏览器验收截图等待正确模板加载完成后再拍摄，避免把加载蒙层误当作最终视觉。

## 可重复生成的样张

运行 `npm run review:visual`，产物位于 `release/visual-review/<时间>/`：

- `index.html`：可离线打开，长图按 375px 宽度并排比较，提供 PDF 和原图入口。
- `template-overview.png`：五套模板的封面对照图。
- `<模板>/pdf/`、`<模板>/image/`：正式渲染器生成的 PDF 和 JPEG。
- `report.json`：浏览器／渲染器版本、页数、分段数和实际字号。

同一份虚构资料包含新人姓名、日期、品牌、交付说明、演示链接、长段落、横图上下对比和竖图左右对比。测试图带完整边框、渐变和前后标记，用于发现裁切、比例或顺序问题，不用于判断真实人像的肤色与调色质量。样张二维码仅指向 example.com。

脚本不启动项目服务，也不读取或改写用户工作区。每次运行使用新的输出目录。
