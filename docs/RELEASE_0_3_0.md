# v0.3.0 · 回收站与章节排序

2026-09-29。增加项目删除与恢复、章节拖拽排序，并统一首尾章节和导出附录的位置。

## 项目回收站

- 项目卡片的“⋯”菜单包含复制、归档和删除。删除前显示项目名称与确认弹窗。
- 删除后移入回收站，保留完整内容、图片和历史交付；页面提供撤销删除。
- 回收站显示删除日期，可恢复到删除前的普通或归档分类，不自动过期清空。
- 回收站内不能编辑、复制或导出。其他窗口的旧草稿不能覆盖已删除或恢复后的新版本。
- 彻底删除需再次确认，清理本项目的数据库记录、受管理的图片原件与副本、预览、导出文件。个人方案继续保留。
- 源素材目录、网盘文件及另存到其他位置的文件不属于清理范围。
- 导入、读取或导出占用项目时暂不允许删除。文件清理失败或程序中断时保留待删除标记，重开后可继续清理；此时不能恢复部分数据。

## 章节排序

- 左侧中间章节通过手柄拖动，显示卡片浮起、邻项让位和插入线。支持鼠标与触屏，靠近列表边缘时自动滚动。
- 手柄支持键盘：空格或回车拾起，上下方向键移动，Home/End 移到中间区域两端，空格或回车放下，Escape 取消。
- 保留上移、下移和撤销上次调整。松手后自动保存并更新预览，章节编号随顺序更新。
- 序言与新人信息固定开头，摄影师署名固定结尾；仍可编辑、隐藏，但不能删除或调整位置。
- 新建章节和自动对比章节放在署名前。应用方案、复制、保存及重新打开项目遵循相同规则。
- 旧项目保留中间章节的相对顺序，只归位首尾；旧项目若缺少首尾章节，补回隐藏的编辑入口，不自动新增客户可见内容。
- 制作附录移动到署名前，五套模板的快速预览、PDF 和长图使用相同顺序。

## 升级与历史文件

工作区兼容标记升级到 3，旧版程序会拒绝打开。升级前退出 Studio 并备份整个数据目录；如需回退，恢复完整备份。渲染器标记为 `studio-renderer-5`，旧成功文件保留原样，旧失败任务跨渲染器版本时需新建导出。

Windows 默认数据目录为 `%LOCALAPPDATA%\WeddingDeliveryStudio`，与程序文件夹独立。解压新版程序不需要搬动项目数据。
