## 1. 用户任务与阶段边界

摄影师在 Windows 浏览器中制作，客户主要在手机上阅读输出。
摄影师主要判断三件事：交付内容、视觉选择、结果是否正确。
系统处理目录遍历、明确规则配对、内容排版、输出检查与文件生成，并集中呈现例外。
当前仅完成产品和技术设计；浏览器工作台加本机服务仍为建议，尚未确定安装方式。

| 阶段 | 本阶段需要达到 | 不混入本阶段 |
| --- | --- | --- |
| 当前设计 | 流程、信息结构、对象边界、异常行为、输出策略、验证计划可供评审 | 编码、搭建工程、承诺已验证的视觉或性能 |
| 后续完整 MVP | 保存项目、方案、整目录导入、自动与手动配对、模板与布局、三种输出 | CRM、日历、云端账号、客户 Web 发布、计费、自由页面编辑器 |
| 后续演进 | 浏览器云端登录管理、适配现有 Worker，再按需求进入生产管理与 SaaS | 当前预建完整团队权限和运营后台 |

建议 MVP 以一份项目默认一份交付文档呈现；保留独立文档身份，暂不增加批次管理入口。
当前为两个视觉模板预留共同能力与方向；具体美术另行设计，不把占位定义等同于完成模板。
建议最终可用 MVP 提供两个经过真实内容验证的模板；这是后续实现范围，不是当前必须生成的美术产物。
独立“客户管理”页面暂缓；在项目中编辑称呼和新人资料即可，底层可保留 Client 身份。

## 2. 信息架构与工作台线框

建议导航：项目列表、项目工作台、工作室设置。低频设置不占据主工作流。
项目列表提供创建、继续编辑、复制、归档和最近导出；不把“已导出”显示成“已交付”。
建议“复制为另一场婚礼”默认只复制通用内容、结构与视觉，清空原客户、日期、交付链接和项目图片；保留专属资料需明确选择范围，避免把前一对新人误带入新交付。
工作室设置只包含品牌、我的方案、识别规则、数据位置与恢复入口；保留策略尚待技术验证。

```text
项目列表
┌ 创建项目 ─ 搜索 ─ 状态筛选 ─────────────────────────┐
│ 项目称呼／编号   婚礼日期   编辑状态   最近导出   打开 │
└─────────────────────────────────────────────────────┘

项目工作台（桌面宽屏建议）
┌ 返回项目 ─ 项目称呼 ─ 已保存／保存中／保存失败 ─ 导出 ┐
│ 内容 · 素材与对比 · 视觉       检查：需处理 2／提示 1 │
├ 文档章节 ─────┬ 当前编辑区 ───────┬ 手机阅读预览 ─────┤
│ 客户与封面    │ 仅展开当前任务    │ PDF／长图          │
│ 交付清单      │ 字段、条目或图片  │ 当前章节定位       │
│ 制作说明      │ 就地显示问题      │ 正式预览入口       │
│ 调色对比      │                  │                    │
│ 观看与保存    │                  │                    │
│ 修改说明／署名│                  │                    │
└──────────────┴──────────────────┴────────────────────┘
```

章节由方案初始化，允许排序、编辑和显隐；不把示例章节全部设为必选。
不含对比的方案不创建空对比章节；用户仍可后续主动加入。
窄桌面窗口采用“编辑／预览”切换，避免强行挤压三栏；不是建设移动端制作工作台。
“内容”编辑交付承诺与文字；“素材与对比”处理素材事实；“视觉”选择模板和局部布局。
跨入口保留编辑位置和选择；异常点击后定位到对应字段、条目或图片槽位。
常见修改直接在项目完成，只有“保存为方案”等复用动作进入额外对话框。
自动保存状态始终可见；颜色之外同时使用文本，键盘操作与焦点顺序可理解。

## 3. 最小字段与展示规则

草稿允许缺信息。导出只检查当前可见、被引用的内容及所选输出要求。
“自动值”“是否显示”“是否已经填写”是独立维度；关闭显示不删除原值。
下表默认行为均为建议，字段必填的最终范围待真实模板验证。

| 字段／对象 | 建议初始行为 | 何时需要用户处理 |
| --- | --- | --- |
| 项目内部标题 | 根据已填称呼生成，可修改；未填时使用项目编号 | 不要求为建草稿额外填写标题 |
| 项目编号 | 自动生成可修改；默认仅工作台显示 | 重复业务编号给出提醒，仍使用稳定 ID 区分项目 |
| 客户称呼 | 可填写，也可由新人展示名称组成；默认显示已填写值 | 封面启用却缺少任何展示称呼时阻止导出 |
| 新人展示名称 | 支持一组可编辑名称，不强制“新郎／新娘”两字段 | 用户选择独立展示时需有对应值 |
| 婚礼日期 | 日历日期；建议显示，可关闭 | 开启显示但为空时提示补填或明确关闭 |
| 交付日期 | 建议自动取工作室日期并显示，可手填或隐藏 | 手动模式且开启显示却为空时需处理 |
| 摄影师／工作室 | 从品牌设置复制此次展示值，可修改 | 署名模块开启却没有有效名称或署名时需处理 |
| Logo | 有配置时可使用；无 Logo 可采用文字品牌 | 选用的 Logo 失联时需换图或取消 Logo |
| 内部备注 | 默认不进入交付展示数据 | 始终不得因模板切换出现在客户输出 |
| 交付备注 | 单独编辑，建议填写后再主动启用 | 开启但空白时作为可清理提示 |
| DeliveryItem | title、description、format、交付方式、资源、visible、order | 可见条目必须有标题；选外链交付时需要对应链接 |
| 制作／建议模块 | 从方案复制标题和正文，允许独立编辑、隐藏和排序 | 可见模块仍含占位符或没有有效内容时需处理 |
| Comparison | 独立 Before／After 槽位、标签、说明、顺序与可见性 | 仅可见且使用的组必须两图可用 |
| 输出配置 | PDF、PDF + 长图、长图；保存项目上次选择 | 最终创建任务前明确显示本次选择 |

工作室时区建议在首次设置时从 Windows 检测并展示供修改；不使用服务器时区替用户决定日期。
可见自动交付日期在正式预览候选中固定；未提交候选跨工作室日历日后刷新并标明变化。已提交版本及其后续重试保持原日期；隐藏自动日期不因跨日增加确认。
展示值只用于此次文档；更新品牌或客户资料不能暗中重写历史导出。
DeliveryItem 的格式、时长、大小等没有数据时省略属性，不伪造“0 秒”或“未知格式”面向客户。
外链区分播放、下载与提取说明；“音频处理”可属于制作说明，不强制建成待交付音频文件。
系统仅在所选交付方式确实要求资源时检查资源；仅作说明的条目不被强迫添加 URL。
列表章节与内部条目的显隐分层处理；关掉章节可保留条目选择，再开启时恢复原选择。

## 4. 普通流程：系统完成确定的工作

1. 创建项目，选择可编辑方案或空白开始；立即形成可保存草稿。
2. 在交付清单中确认本次交付项目，必要时改客户信息；不强制按固定页面顺序完成。
3. 拖入文件夹，系统说明将扫描目录信息并仅导入文档用图；显示数量、进度与取消入口。
4. 读取可访问文件并分类；报告范围区分“已扫描”“无法读取”“未支持”“文档用图”。
5. 对明确且无冲突的规则自动建立 Comparison，异常进入待处理区域。
6. 用户处理例外，选择模板和布局，在手机宽度预览中看最终内容。
7. 点击导出，先等待当前编辑成功保存并取得版本回执，再检查所选目标并展示正式预览与产物摘要；修正共用输入阻塞或确认有具体影响的警告。若只阻塞某一目标，提供“先生成可用目标”，明确另一目标仍被阻塞，不要求全部目标通过才允许继续。
8. 生成完成后提供打开、保存产物与失败重试；PDF + 长图分别报告结果。

文件夹含“音频”不代表客户会收到音频；发现结果只作为事实或建议，不自动增加交付承诺。
百度网盘已有完整成片链接时，不要求导入同一完整视频。外链未验证与已失效需分开显示。
发现的目录与文件不必全部进入文档；未使用素材可留在报告中，不造成阻塞。
扫描可取消且已保存编辑不丢；取消后明确显示只分析了部分目录，不能报告“全部完整”。

## 5. 例外工作区与人工接管

```text
扫描完成：6 组已匹配 · 1 组缺图 · 1 项链接待填
[只看需处理] [全部结果]                  [重新扫描]
缺图：Comparison 07   Before [空]  After [缩略图]
原因：按已选规则找到 07-1，未找到对应 Before
[选择 Before] [从未配对图片选择] [不在本次显示]
```

以上计数仅为交互示例；产品中的计数必须来自当前扫描和当前版本内容。
“明确匹配”是可直接采用的状态，不要求点击每一组“确认正确”。
首次使用 `-1 → After、-2 → Before` 时建议预览代表组并确认整条规则；之后不逐组再问。
系统显示规则来源与前后标签，用户可以查看全部结果、批量交换或修正任意一组。
批量改变已有关系时展示影响数量和示例；已手工修改的组建议默认不纳入批量修改。
批量交换、批量规则应用应以一次操作提交并支持撤销，不要求逐组确认，也不改写源文件。
重新应用 Preset 前列出新增、替换、隐藏及保留的内容，明确人工编辑会受何影响；提交后可撤销本次变更。
弱规则或冲突候选只提出建议；用户选择后才改变关系，不用未经校准的百分比代替解释。
自动结果与手工覆盖记录分开；重扫增量报告新文件和变化，不覆盖人工决定。
被排除的发现、隐藏的 Comparison 保留该决定；重扫不能重新加入文档，只有明确恢复操作才能加入。
重复导入不重复建组；改名或覆盖造成不确定时，指向原 Asset／Comparison 请求重新定位或复查。
忽略某个发现、隐藏一组对比、删除组关系、删除源文件是不同动作；MVP 不提供删除源文件。
人工处理支持交换、替换、补图、拆组、手工组对、排序和排除，均不要求按命名规范重命名文件。
警告确认绑定内容和资产版本；未变化时不重复确认，换图或链接变化后重新检查。

## 6. 异常流程与可恢复行为

| 情况 | 应呈现的事实 | 用户可采取的动作／系统结果 |
| --- | --- | --- |
| 本次不需要对比图 | 对比章节未启用，扫描无图不是错误 | 正常完成纯文字与交付清单导出 |
| 已启用对比但无完整可见组 | 章节为空或组不完整，不能假装已生成对比 | 添加／修复图片或明确关闭章节；不自动关闭或消失 |
| 缺一张对比图 | 定位具体组和空槽位 | 补图、换图或明确隐藏该组；可见缺对阻止输出 |
| 同编号多个候选 | 并列候选并给出目录来源 | 选择或拆组；不静默覆盖其中一张 |
| 不支持格式／解码失败 | 列出文件与原因，不报告成成功导入 | 换图或排除；仅使用该图时阻止输出 |
| 目录权限失效 | 原目录暂不可读取，管理副本状态独立显示 | 重新授权扫描；已有可用文档副本继续预览与输出 |
| 原图变更／失联 | 分开显示源文件状态与文档副本状态 | 保留现用版本，选择更新或重新定位，历史产物不变 |
| 交付链接为空 | 当前交付方式需要链接 | 补链接或改交付方式；不能替用户编造链接 |
| 外部访问无法验证 | 尚未验证，写明网络或服务限制 | 手动检查并确认；不把可打开网页等同于资源可下载 |
| 长图超过限制 | 预计尺寸、失败原因与可行选项 | 预览分段或降尺寸效果后选择；不静默截尾或分段 |
| 图片／文字溢出 | 具体章节和所选输出目标 | 换布局、改内容或接受明确支持的拆分方式 |
| 只有 PDF 或长图预检被阻塞 | 区分可用目标与受影响目标 | 共用输入有效且一个目标正式预览就绪时，可明确先生成可用目标；保留另一目标阻塞记录 |
| 保存失败 | 持续显示失败与最后成功保存时刻 | 保留当前内存编辑、重试；恢复前阻止从旧数据导出 |
| 本机服务不可用 | 当前输入尚未保存，预览可能过期 | 保留页面，显示重连与恢复入口；不显示“已保存” |
| PDF 成功、长图失败 | 部分完成及每个产物状态 | 打开已成功 PDF；仅重试同一版本的长图 |
| 导出中断 | 任务未完成，不损坏先前成功产物 | 重试任务；不要求重新录入整个项目 |

保存失败时可以继续查看和修正，但明确提示不要关闭页面；不能承诺浏览器崩溃后恢复未落盘编辑。
导出期间仍允许编辑草稿，新编辑不改变正在生成的快照；完成时显示“此后草稿有更新”。
预览正在刷新或内容未保存时标记状态，不让旧预览看起来像最新结果。
隐藏阻塞内容必须由用户明确选择，并更新“本次输出包含什么”的摘要。
系统异常与内容问题分开：重试不能修复缺图，修改字段也不能解决磁盘写入失败。

## 7. 手机阅读与输出交互

编辑预览建议模拟手机宽度，PDF 显示页面边界，长图显示连续文档及预计分段位置。
9:16 PDF、1080 像素宽长图仅为试排参数；真实字号、长宽与文件体积没有在本阶段定案。
对比布局建议默认 Stacked，Split 可选；保留完整画面与清楚的 Before／After 标签。
两张图若比例或方向不同，提示比较影响；不为对齐静默改变图片内容。
图片裁切若后续支持，需要同步呈现两个裁切结果；MVP 可先仅提供完整显示。
PDF／长图切换不会改变文案或配对。某布局不支持目标时，在选择阶段说明可用替代。
普通实时预览便于编辑；正式预览应来自与导出一致的渲染规则，不能宣称任意浏览器像素完全一致。
字体、正文长度、对比细节需要在实际手机和发送渠道检验，不能只看桌面上的缩略图。
PDF 保留文本与链接；长图链接不能点击，设计上必须明确可见访问指引的表达方式。
建议长图对需要访问的交付资源默认提供带用途标签的二维码和取件说明，只编码授权显示的稳定分享 URL，不预建短链服务，也不编码临时 S3 地址或系统凭据。实际渠道中无法识别时明确替代方式，如提供稳定分享链接或由用户确认另发可复制交付说明；这些表现仍需样张验证。
输出面板同时显示目标、内容版本、日期与已排除章节；生成文件不等于已发送客户。

## 8. 虚构代表场景演练

以下“林岚与周屿”、日期、目录、数量和内容均为虚构测试场景，不来自用户 Canva 或电脑。
假定项目婚礼日期为 2026-09-12，自动交付日期按设置解析为 2026-09-26。
用户选择一个示例方案：完整成片通过百度网盘交付，显示 LOG 制作说明、对比、保存建议与署名。
用户填入示例称呼与交付信息；示例方案不代表用户已经批准的套餐或文案。
导入文件夹包含三组 `01-1/01-2` 至 `03-1/03-2`，另有 `04-1` 和一个音频目录。
确认当前数字命名规则后，系统建立三组完整对比，并报告第四组缺 Before；音频仅记为发现。
用户在待处理区域补入任意名的原图，系统沿用第四组 Comparison ID，不要求用户改文件名。
如果决定不展示第四组，用户可明确隐藏；前三组无须逐组点击通过。
百度网盘链接已填则不存在“本地缺完整成片”阻塞；离线时仍显示外链尚未验证。
用户选择某个模板方向与 Stacked，检查手机预览，再选择 PDF + 长图。
两个输出来自相同内容与日期；若长图超过限制，先提供分段或降尺寸预览让用户决定。
成功后记录各产物；以后改署名只影响草稿或新版本，不改写本次 PDF 与长图。

## 9. 当前设计审查与后续验收

当前设计评审应检查：关键对象含义一致、流程没有多余确认、异常有出口、未确认默认有标注。
本文完成意味着流程可供讨论，不代表用户已经批准字段、已实现功能或已完成手机实测。

| 后续实现验收场景 | 需要看到的证据 |
| --- | --- |
| 普通交付 | 从项目创建到三种输出均有完整操作与结果；无需逐组批准明确配对 |
| 不使用对比图 | 关闭对比章节后可生成完整交付，无伪造占位图或无关阻塞 |
| 缺对与人工修正 | 每个可见缺对可定位；补图、隐藏、手工组对后检查结果同步变化 |
| 重扫与重复导入 | 手工关系未被覆盖，无重复 Comparison，不恢复已排除项；变更有明确报告 |
| 方案和模板修改 | 改方案不改已有项目；重应用展示影响且可撤销；换模板不丢条目、顺序和手动显隐 |
| 批量调整 | 变更范围可见、可一次提交和撤销，无逐组重复确认；人工修正默认受保护 |
| 手机阅读 | 真实文案与图片在代表性手机、PDF 阅读器和分享渠道中可读且未截断 |
| 长图超长 | 超限可被检测；用户选定的分段／尺寸与最终产物一致 |
| 保存和输出失败 | 输入、已保存草稿和成功产物不被错误覆盖；失败状态和重试真实有效 |
| 历史记录 | 输出版本不会随草稿或品牌修改漂移；明确显示双输出部分失败 |

后续应以真实样本验证字段、默认显隐、文字长度、图片方向、文件类型和发送渠道压缩。
真实性样本缺失不阻止当前信息结构设计，但不足以冻结模板美术、页尺寸或性能指标。

## 10. 与架构总览一致的关键约定

- 明确规则的无冲突结果直接采用，用户查看整体预览，不逐组审核全部自动配对。
- 两个视觉模板在当前设计阶段是能力与方向预留；具体美术和实测属于后续工作。
- 没有对比图不代表项目不完整；是否阻塞由本次可见内容和交付意图决定。
- 历史版本与恢复是可靠性能力，MVP 不因此引入复杂版本分支或审核流程。
- 字段值、章节显隐、条目显隐与布局覆盖必须只有一个明确归属，UI 不另存一套规则。
- 长图没有可点击链接，需要补充访问指引设计；不能照搬 PDF 链接的交互承诺。
