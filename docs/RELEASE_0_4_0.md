# v0.4.0 · 模板视觉升级、高光与分享卡

2026-10-02。重做五套模板的封面和阅读节奏，新增高光画面、当天时间线、封面预告链接与 9:16 分享卡；发布包增加不内置浏览器的 Windows 精简版。

## 封面与字体

- 五套模板各有独立封面版式：Editorial 杂志刊头、Cinematic 胶片取景框、Archive 档案卡片与圆章、Correspondence 拍立得与邮戳、Gallery 展框与展签。
- 新增思源宋体中文子集（Studio Serif SC），标题与姓名使用衬线字体。正式导出 HTML 约增加 7.8MiB，仍在 96MiB 预算内。
- 自动识别并去除截图上下黑边；竖图封面不裁切照片，周围用同一张图的模糊背景填充。一组对比图共用同一裁切范围，前后画面严格对齐。
- 封面寄语是独立分页单元；部分模板的 PDF 中寄语会落在第 2 页。
- 品牌色只用于署名区；与模板背景对比度不足 3:1 时改用模板色，保证可读。

## 阅读节奏

- 调色章节开头增加“左半原片／右半成片”对切大图，只选用前后尺寸一致的一组。
- 交付条目改为票根式卡片：格式拆成标签，增加“获取方式”，跨页时上下两半各自完整。
- 署名前增加收尾大图与模板结束语，优先使用与封面不同的调色成片。
- Cinematic 章节号改为场次与时间码，如「SCENE 02  00:02:00:00」。

## 新内容

- **高光画面**：首张满版，其余两两成排，不裁切画面，每张可写一句说明。建议 3–9 张；少于 3 张提醒，超过 9 张或存在未选图片时阻止导出。
- **当天时间线**：时间、标题、说明和可选配图，跨页时时间轴连续。
- **封面预告链接**：长图在封面下方显示二维码，PDF 显示可点击链接。链接无效时阻止导出；链接过长、二维码不易识别时只阻止长图。
- **分享卡**：选择长图时额外生成 `wedding-share-card.jpg`（1080 × 1920），包含封面画面、姓名、短句、寄语、日期和预告二维码，五套模板各有装饰。它随长图结果一起生成、下载和重试，长图预览页排在最后。
- 复制项目或保存为方案时：高光画面保留张数、清空图片和说明；时间线保留时间和标题，清空说明和配图；预告链接移除。
- “采用新版本”现在也会更新高光画面、时间线、封面和制作说明图引用的图片。

## Windows 精简版

- `npm run package:windows:lite` 生成 `WeddingDeliveryStudio-<版本>-win-x64-lite-<时间>.zip`，不含 Chromium，体积约小 170MiB。
- 导出浏览器查找顺序：`WDS_CHROMIUM_PATH` → 本机 Microsoft Edge → Google Chrome。启动窗口会显示所用浏览器；都找不到时仍可编辑项目，导出会提示安装或指定浏览器。
- 导出效果取决于本机 Edge／Chrome 版本。浏览器自动更新后，旧导出的“重试”会要求新建版本，已生成文件不受影响。需要多台电脑输出完全一致时使用完整版。
- `build-manifest.json` 记录 `variant: "lite"`，`chromiumVersion` 为 `null`。

## 升级与历史文件

工作区兼容标记升级到 4，旧版程序会拒绝打开，避免 v0.3.0 读到新章节类型时出错。升级前退出 Studio 并备份整个数据目录；如需回退，恢复完整备份。渲染器标记为 `studio-renderer-6`，旧成功文件保留原样，旧失败任务跨渲染器版本时需新建导出。
