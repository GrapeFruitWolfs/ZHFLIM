# v0.2.0 · 私人影像展册

2026-09-28。本轮将真实案例的排版构思接入本地工作台与正式导出，仍采用本机保存、浏览器编辑的使用方式。

## 可用的新能力

- Editorial 主模板采用浅色画布、中文信息层级和新人优先的封面。正文在 432px 版面上为 18.5px，按 375px 宽查看时约为 16px。
- 在“序言与新人信息”中选择“姓名主导”或“照片主导”，编辑封面短句与寄语，上传或选用项目图片。封面图片保留完整构图。
- 文案章节可添加技术说明、制作图片与图注，选择随正文展示、进入文末附录或本次隐藏。隐藏的内容与图片不会进入客户展示数据，也不参与导出素材读取。
- 每组对比可添加说明文字；原始图片、人工配对与版本引用继续保留。
- PDF 按实际空间安排相邻标题与正文；短章节采用紧凑标题。制作说明与相邻证据图尽量一同排版。超出范围时提示具体页或长图段及对应章节。
- 长图短分段不足以同时容纳多级标题与二维码时，合并标题上下文，保留完整二维码、文字和关联。
- 五套模板选择卡使用正式渲染器生成的虚构样例截图。项目自身的封面、文案和照片在右侧实时预览。

## 数据与升级

新字段为可选字段，旧项目可继续读取。工作区兼容标记从 1 升为 2，已有项目内容保持不变，旧版程序会拒绝打开升级后的工作区，避免无法理解新字段时覆盖资料。升级前退出程序并备份整个数据目录；需要回退时恢复备份。

复制项目与保存方案不会带入封面图片、个人寄语、制作证据图片或图片说明。原有文本模块继续作为可编辑文案复用。

渲染器标记为 `studio-renderer-4`。旧成功文件继续保留；旧失败任务若需要跨渲染器版本重试，应从当前项目创建新导出。

## 真实案例样稿

根据用户提供的 PDF，重排两种封面方案，包含：交付清单、三段制作说明、三组对比、观看保存建议、修改约定、署名和制作附录。原文件没有提供下载地址，样稿使用“交付链接待填写”，没有编造二维码或有效链接；交付日期暂不显示。

前后关系遵循原稿标注。其中一组画面中的人物动作不同，样稿明确说明它是同场景观感展示，不是严格的同帧对照。

真实参考照片和工作区只存在本地 `release/` 中，不作为程序默认数据、不进入公开测试样例、不包含在 Windows 应用包内。

## 开发与复核

- `npm run build:previews`：用正式模板生成默认封面缩略图，输出到 `public/template-previews/`。
- `npm run review:visual`：生成五模板的虚构资料与测试图样张。
- `npm run review:case -- /path/to/private-case.json`：从显式指定的本地案例文件创建独立工作区，并生成两种封面的 PDF、长图及离线手机预览。不会读取默认工作区。
- `npm test`：含新字段归属、隐藏素材、复制清理、工作区升级、PDF／长图及导入回归。
- `npm run test:e2e`：覆盖封面上传、制作附录、隐藏详情、保存重开及正式双格式预览。
- `npm run test:runtime`：核对本机启动器、导入、导出及重开。

## 本轮边界

当前封面采用完整图片，不提供自由裁切、焦点拖动或任意版面编辑。PDF 继续使用手机比例 9:16；实际内容决定页数，技术附录可能增加页数。Web 客户页面、账号登录、播放器与远程发布尚未接入。

PDF 栅格图与自动化浏览器可核对内容、排版和资源加载，Windows、手机与微信的真机效果仍由实际设备确认。
