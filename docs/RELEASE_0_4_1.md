# v0.4.1 · 模板版面精修

2026-10-02。不新增功能，用真实案例逐页检查五套模板后修正版面：对比章节更短、高光不再有色带、收尾与署名合为一屏、PDF 空页明显减少，分享卡改为拼版。项目数据结构不变。

## 调色对比

- 对比有 2 组及以上时，开头的对切大图所用那组不再在下方重复列出，它的说明文字接在对切图下面。只有 1 组时不做对切，直接完整展示前后两张。
- Before／After 改为贴在图片角上的小标签，不再每组重复一行“原始画面／调色成片”。
- 新建项目（三个内置方案）默认“左右并排”。已有项目保留原来的布局设置。

## 高光画面

- 画框比例跟随图片本身，不再固定 3:2，横图上下不再出现灰色或黑色色带；同一排两张按各自比例等高排列。
- 没有写说明的画面不再显示孤零零的编号。
- 第一张也使用模板画框：Archive 白边相纸、Cinematic 胶片条（整组高光在同一条胶片里）、Correspondence 拍立得、Gallery 展框；Editorial 保持满版。

## 收尾与署名

- 收尾大图从已出现的调色成片和高光画面中选择画面最干净的一张（按局部对比度估算“杂乱程度”），不再选俯拍人群这类杂乱画面；仍不使用封面和调色前原图。
- 结束语放在图片下方，不再压在照片上。
- 收尾图与署名合为一屏，PDF 中保证同页；有收尾图时署名里的大号结束语隐藏，避免与收尾标题重复。
- 文档末尾的标语与署名绑定，不再单独落在最后一页。
- Correspondence 落款改为信件式：小号“With gratitude,”接斜体签名。

## 制作附录

- 「制作附录」标题使用与其他章节相同的样式，按模板显示 Appendix／END CREDITS／RECORD APX／Enclosed.／APPENDIX。
- 每条说明改为“左文字、右缩略图”的紧凑卡片，截图只作示意，不再整屏放大。
- PDF 中附录不再强制另起一页，直接接在正文后。

## PDF 分页

- 修正分页时“当前页剩余空间”始终计算为 0 的问题，原有的图片缩放从未生效。
- 一组内容差一点放不下、而本页还剩至少 1/4 时：先把组内图片缩小（最多到 74%），仍放不下则把长段落在句号处拆开，后半接到下一页。
- “保持在一起”改为优先规则：一组内容整页都放不下时，先缩小图片，再逐个排版，不再报“内容超过可读范围”。
- 真实案例（上下排列）：PDF 从 16–18 页降到 12–13 页，长图从 8–9 段降到 6–7 段；除最后一页外，每页至少用到 55%。左右并排时 11–12 页。

## 分享卡

- 主图为横图且有至少 2 张其他已出现的画面时，改为“一大两小”拼版：小图从封面、高光画面、调色成片中选取（不用调色前原图，不重复），优先画面干净的。
- 只有一张横图时放大文字并垂直居中；竖图按图片比例设框。分享卡不再使用模糊填充。
- 顶部品牌行加大加深，清晰可读。

## 其他细节

- 文字章节的英文副标题按内容区分：制作说明为 Production notes，观看与保存为 How to watch，修改说明为 Revisions；判断不出类型的自定义章节不显示副标题。
- 交付卡的最后一行“获取方式”与前文绑定，不再单独落到下一段开头。
- 预告卡按模板区分：Editorial 杂志侧栏、Cinematic 电影票存根、Archive 穿孔吊牌、Correspondence 邮票、Gallery 展签；二维码缩小到 72–84px。
- 时间线圆点与标题之间留出间距。

## 升级与历史文件

工作区兼容标记仍为 4，可直接打开 v0.4.0 的工作区，无需迁移。渲染器标记升级为 `studio-renderer-7`：旧成功文件保留原样，已生成的候选结果需要重新渲染，旧失败任务需新建导出。

## 验证范围

新增单测覆盖：画面杂乱程度评分、收尾选图、对切组不重复、单组不对切、新项目默认并排、高光框比例与无说明不显示编号、章节副标题分类、标语与署名绑定、分享卡拼版选图。已用真实案例检查五套模板的 PDF、长图和分享卡，并与 v0.4.0 逐页对比。
