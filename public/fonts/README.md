# Bundled fonts

Noto Sans SC and Source Serif 4 are distributed under the SIL Open Font License 1.1.
The unmodified font files and their copyright/license texts are included here for offline rendering.

- Noto Sans SC: https://github.com/google/fonts/tree/main/ofl/notosanssc
- Source Serif 4: https://github.com/google/fonts/tree/main/ofl/sourceserif4

Downloaded for this project on 2026-09-26. The application renders locally and does not fetch Google Fonts at runtime.
